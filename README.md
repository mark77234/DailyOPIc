# DailyOPIc

**DailyOPIc**은 오픽(OPIc) 스피킹 시험을 준비하는 사용자를 위한 학습 앱입니다.  
카테고리별 문제를 읽고 **음성으로 답변**하면, **음성인식 기반 분석**으로 예상 등급과 피드백을 확인할 수 있어요.  
또한 **문제별 샘플 답안**을 제공해 내 답변과 비교하며 실력을 빠르게 끌어올릴 수 있습니다.

</div>

---

## ✨ 핵심 기능

- **카테고리별 OPIc 스피킹 문제 제공**
- **음성 녹음 → 음성인식 기반 답변 분석**
- **답변 기반 예상 등급 제공**
- **문제별 샘플 답안 제공** (내 답변과 비교 학습)
- **통계/최근 기록 페이지로 학습 흐름 한눈에 확인**
- **연습 기록 상세 보기 & 관리(삭제/전체 삭제)**

---

## 🧭 사용 흐름 (User Flow)

1. **목표 등급 선택**  
   - 예: IM1, IM2 등 목표 레벨을 선택해 학습 방향을 고정합니다.
2. **문제 확인 & 녹음**
   - 카테고리/태그와 함께 제시되는 질문을 읽고 **마이크 버튼을 눌러 답변**합니다.
3. **분석 결과 확인**
   - 예상 등급, 발화 요약(문장 수/단어 수 등), 피드백을 확인합니다.
4. **샘플 답안으로 비교 학습**
   - 같은 질문의 샘플 답안을 참고해 표현/구성/흐름을 개선합니다.
5. **통계에서 성장 체크**
   - 최근 기록과 요약 정보를 통해 “오늘의 연습”이 쌓이는 걸 확인할 수 있어요.

## 🧩 무엇을 분석하나요?

DailyOpic은 사용자의 답변을 기반으로 다음과 같은 학습용 인사이트를 제공합니다.

- **예상 등급(연습용)**
- **발화 요약 정보** (예: 문장 수, 단어 수 등)
- **피드백** (예: 문장 구성/길이/흐름 개선 포인트)
- **샘플 답안 제공**으로 비교 학습 지원

> 참고: 앱 내 표시되는 등급은 학습 동기 부여를 위한 **연습용 지표**이며, 실제 OPIc 결과와 다를 수 있습니다.
